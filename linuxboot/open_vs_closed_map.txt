# The ONLY region LinuxBoot opens: the MAIN DXE FV @ 0x94f000 (0x4f0000 = 4.9 MiB on-flash,
#   ~12.6 MiB decompressed, 309 DXE drivers). Everything else stays AMD-signed/AMI and is required.
# Open fraction of the 16 MiB image (by on-flash size): ~31%.
# * NVRAM is AMI-format but user data; typically preserved or reset, not "opened".
#
# What stays closed and WHY it cannot be opened on this board:
#   - PSP bootloader/ABL/SMU/PMU/SEC-gasket : AMD signed; the on-die PSP verifies them before x86 runs.
#   - AGESA (in PEI FV) : AMD memory/fabric init; no open replacement for AM4 desktop (openSIL is Zen4+).
#   - Promontory FW : AMD signed chipset firmware; required for USB/SATA/PCIe.
#   - CPU microcode : AMD signed.
#   LinuxBoot keeps all of these and only swaps the UEFI DXE/boot environment for Linux+u-root.
